# petroleum-paper-workflow
面向油气工程与地质力学研究的 Codex Skill，帮助核对数据与模型工况、复算关键结果，并追溯论文结论、图表和引用的证据来源。
# 油气论文证据链与复现

`petroleum-paper-workflow` 是面向油气工程和地质力学研究的 Codex Skill。它帮助研究者从已有数据、模型或稿件接续工作，核对研究问题、比较条件、计算方法、图表与结论是否对应。

## 适用场景

- **研究设计**：明确比较对象、参考状态，以及每项分析能支撑的结论。
- **数据与模型**：在批量分析前核对网格、时间步、实际曲面、深度基准、单位和样本配对。
- **稿件修订与投稿前检查**：根据正文复算关键结果，核对实际嵌图、图注、引用和交付版本。

适用于数值模拟、测井与储层评价、岩石力学实验以及生产动态分析。Fault1 为脱敏案例，具体工况、统计量和阈值由新项目的研究问题决定。

将整个仓库目录作为 Skill 安装到 Codex，保留 `SKILL.md` 和 `references/` 的相对位置。安装后，可以直接输入：

> 使用 $petroleum-paper-workflow，基于现有稿件、统计表和图源，核对主要结论是否能追溯到对应工况与计算步骤，优先指出会影响结论或复现的问题。
